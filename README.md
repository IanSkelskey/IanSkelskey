**Software engineer building systems, tools, and games.**

I work in the **Evergreen ILS** ecosystem as an Evergreen Systems Specialist at **Bibliomation Inc.**, on open-source library software serving Connecticut's largest library consortium. On my own time I build developer tools, small browser games, and pixel art.
