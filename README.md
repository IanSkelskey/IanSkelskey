# Hello, I'm Ian Skelskey 👋

**Software engineer building systems, tools, and games.**

I build web applications, developer tools, and retro-inspired games with a focus on maintainability, clarity, and thoughtful interaction design.

Professionally, I work in the **Evergreen ILS** ecosystem as an Evergreen Systems Specialist at **Bibliomation Inc.**, contributing to open-source library software serving Connecticut's largest library consortium.
